# Caesar Cipher 3

This is the most complete Caesar cipher version in the Day 8 exercises.

The project separates the art asset from the main logic and presents a more polished program structure that is closer to a real project.

## Files

- `main.py`: runnable project.
- `solution.py`: reference solution.
- `art.py`: ASCII art and banner text.

## Learning Goal

- Organize a project into logic and presentation files.
- Improve readability while keeping the same core cipher behavior.
- See how a small program becomes more professional with better structure.
