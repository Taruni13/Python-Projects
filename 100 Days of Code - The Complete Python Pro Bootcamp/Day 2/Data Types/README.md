# Data Types

This exercise introduces the main built-in Python types used in beginner code: strings, integers, floats, and booleans.

The lesson helps connect syntax to behavior. Once you can identify the type of a value, it becomes much easier to understand why an expression works or fails.

## Files

- `task.py`: practice prompt for the lesson.
- `solution.py`: completed answer for comparison.

## Learning Goal

- Recognize the basic built-in types.
- Understand how values are stored and printed.
- Start building an intuition for when conversion is needed.
