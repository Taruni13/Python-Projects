# Number Manipulation

This exercise covers the practical side of working with numbers in Python: rounding, formatting, and preparing values for display.

The topic matters because real programs rarely just calculate values; they also have to present those values cleanly to the user.

## Files

- `task.py`: starter exercise.
- `solution.py`: completed solution.

## Learning Goal

- Round values to a sensible number of decimal places.
- Format numbers for readable output.
- Think about how numeric values should appear to a user.
