# Day 2

Day 2 moves from raw syntax into core Python data handling. The exercises cover strings, integers, floats, arithmetic operators, type conversion, rounding, and simple user input.

This day is important because most beginner bugs in Python come from mixing incompatible types or assuming values behave like numbers when they are actually text.

## Contents

- [Data Types](Data%20Types/): inspect and work with Python values.
- [Mathematical Operations](Mathematical%20Operations/): arithmetic and precedence practice.
- [Number Manipulation](Number%20Manipulation/): rounding and formatting numbers.
- [Tip Calculator Project](Tip%20Calculator%20Project/): a small practical calculator.
- [Type Error, Checking and Conversion](Type%20Error,%20Checking%20and%20Conversion/): handling conversions and type problems.

## What To Look For

- The difference between strings, integers, and floats.
- How to convert values with `int()`, `float()`, and `str()`.
- How arithmetic works when calculations are built from user input.
- How to turn a classroom exercise into a useful mini-project.
