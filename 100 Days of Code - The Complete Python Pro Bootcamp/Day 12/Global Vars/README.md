# Global Vars

This lesson explores global variables and how they interact with functions.

It is a useful stepping stone because it helps explain why some state is shared across a program and why that can make code harder or easier to reason about.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- See how global data is accessed and changed.
- Understand the tradeoffs of shared state.
- Recognize why later projects often prefer cleaner state management.
