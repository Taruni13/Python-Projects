# Namespaces and Scope

This exercise shows how Python looks up names across local, enclosing, global, and built-in namespaces.

It is one of the most important conceptual lessons in the course because it explains how Python decides which variable or function name to use.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- Understand the name lookup order.
- Distinguish between scope levels.
- Read code that uses the same variable name in multiple places.
