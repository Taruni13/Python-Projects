# Block Scope

This lesson shows how variables defined inside a block or function behave compared with variables defined elsewhere.

Understanding local scope is essential before using functions in larger programs, because it explains why some names work in one place and not another.

## Files

- `solution.py`: reference solution.

## Learning Goal

- Recognize where a variable can be accessed.
- Understand the idea of local versus outer scope.
- Build confidence reading nested code.
