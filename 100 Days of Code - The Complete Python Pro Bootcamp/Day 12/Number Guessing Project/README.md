# Number Guessing Project

This project turns the scope lessons into a playable number guessing game.

The program uses state, repeated guesses, and game feedback to show how functions and shared values can work together in a larger script.

## Files

- `solution.py`: reference solution.
- `art.py`: game artwork.

## What It Demonstrates

- Keeping track of game state across guesses.
- Using scope rules in a real project.
- Presenting a small game with simple visual flair.
