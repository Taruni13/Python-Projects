# Blackjack Project

This folder contains the Day 11 Blackjack project files.

The project focuses on game state, randomness, and comparing the player and dealer hands in a simple text-based format.

## Files

- `main.py`: the project entry point used during the lesson.
- `solution.py`: the completed reference implementation.
- `art.py`: card and table artwork used by the game.

## Learning Goal

- Combine lists, conditionals, and random choices into a single game.
- Manage the state of a card game across multiple turns.
- Keep presentation assets separate from the gameplay logic.
