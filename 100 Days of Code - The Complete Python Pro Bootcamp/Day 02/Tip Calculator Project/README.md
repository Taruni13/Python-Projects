# Tip Calculator Project

This small console project asks the user for a bill amount, tip percentage, and number of people, then calculates each person's share.

It is one of the first examples in the course that feels like a real utility instead of a pure syntax exercise. It combines input, type conversion, arithmetic, and formatted output.

## Files

- `task.py`: project prompt and starting point.
- `solution.py`: working solution that completes the calculation.

## What It Demonstrates

- Turning user input into usable numbers.
- Breaking a problem into a few clear calculation steps.
- Producing an output that is easy to read and practical to use.
