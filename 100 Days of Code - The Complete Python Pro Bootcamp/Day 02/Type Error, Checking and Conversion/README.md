# Type Error, Checking and Conversion

This lesson focuses on one of the most common beginner problems in Python: trying to use a value in the wrong type.

The exercises teach how to inspect, convert, and combine values so that the program can safely perform the intended operation.

## Files

- `task.py`: exercise prompt.
- `solution.py`: reference answer.

## Learning Goal

- Spot type-related mistakes.
- Convert values before calculations.
- Build confidence reading Python error messages.
