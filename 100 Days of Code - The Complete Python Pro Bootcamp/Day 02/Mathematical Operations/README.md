# Mathematical Operations

This exercise focuses on Python's arithmetic operators and the order in which calculations are evaluated.

It is a foundational lesson because later projects depend on being able to build expressions from user input and variables without guessing how Python will interpret them.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- Use addition, subtraction, multiplication, division, and exponentiation.
- Understand operator precedence.
- Practice combining several numeric operations in one expression.
