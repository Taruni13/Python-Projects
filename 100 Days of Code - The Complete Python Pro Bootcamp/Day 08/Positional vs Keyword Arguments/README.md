# Positional vs Keyword Arguments

This exercise compares positional arguments and keyword arguments in function calls.

The lesson is useful because it shows how the order of inputs can matter and how keyword names can make function calls easier to read.

## Files

- `task.py`: exercise prompt.
- `solution.py`: reference solution.

## Learning Goal

- Learn the difference between positional and keyword arguments.
- Understand how function calls become clearer with explicit names.
- Practice reading and writing flexible function calls.
