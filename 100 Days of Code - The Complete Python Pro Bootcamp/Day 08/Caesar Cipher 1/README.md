# Caesar Cipher 1

This is the first version of the Caesar cipher project. It focuses on the core idea of shifting letters forward or backward in the alphabet.

At this stage the emphasis is on understanding the cipher logic itself rather than refining the user experience.

## Files

- `main.py`: runnable project.
- `solution.py`: reference solution.

## Learning Goal

- Work with string characters one at a time.
- Practice transforming text based on a numeric shift.
- Build the basic mechanism behind a classic cipher.
