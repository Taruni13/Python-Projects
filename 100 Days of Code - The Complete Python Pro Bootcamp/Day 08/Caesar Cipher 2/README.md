# Caesar Cipher 2

This version improves the Caesar cipher by making the control flow cleaner and the code easier to reuse.

It shows how the same problem can be revisited after the first draft to make the solution more maintainable.

## Files

- `main.py`: runnable project.
- `solution.py`: reference solution.

## Learning Goal

- Refine code structure after a first working version.
- Keep the core cipher logic while improving readability.
- Practice iterative problem solving.
