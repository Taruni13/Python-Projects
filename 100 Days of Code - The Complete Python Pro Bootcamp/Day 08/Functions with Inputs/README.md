# Functions with Inputs

This lesson shows how functions become more powerful when they accept inputs through parameters.

Instead of hard-coding values inside a function, the same logic can now be reused with different arguments.

## Files

- `task.py`: starter exercise.
- `solution.py`: completed answer.

## Learning Goal

- Define parameters in a function.
- Pass values into reusable code.
- Understand why inputs make functions flexible.
