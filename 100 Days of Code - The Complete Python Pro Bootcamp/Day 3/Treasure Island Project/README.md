# Treasure Island Project

This is the first story-driven project in the course. The player makes choices, and each choice determines the next part of the story.

It is a useful milestone because it shows how basic conditionals can produce a complete interactive experience.

## Files

- `task.py`: project prompt.
- `solution.py`: working solution.

## What It Demonstrates

- Using nested choices to drive a narrative.
- Turning user input into branching story paths.
- Building a small interactive program from simple `if` statements.
