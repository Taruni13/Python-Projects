# Day 3

Day 3 introduces control flow, which is the point where Python programs start making decisions.

The exercises cover `if`/`else` statements, logical operators, nesting, and the first story-driven project. This day is where beginner code begins to feel interactive.

## Contents

- [If Else](If%20Else/): basic branching.
- [Logical Operators](Logical%20Operators/): combining conditions.
- [Modulo](Modulo/): remainder-based checks.
- [Multiple Ifs](Multiple%20Ifs/): several independent decisions.
- [Nesting and Elif](Nesting%20and%20Elif/): structured branching.
- [Python Pizza](Python%20Pizza/): a beginner pizza-order exercise.
- [Treasure Island Project](Treasure%20Island%20Project/): a text-adventure project.

## What To Look For

- How Python decides which branch to execute.
- Why indentation matters in nested logic.
- How conditions can be combined to make a decision more precise.
- How a simple choice-based story can be built from conditionals.
