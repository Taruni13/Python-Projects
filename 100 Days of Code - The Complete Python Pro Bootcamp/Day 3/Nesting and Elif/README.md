# Nesting and Elif

This lesson combines nested `if` blocks with `elif` branches to build more realistic decision trees.

It is important because many beginner projects need more than a yes-or-no choice; they need layered logic with multiple outcomes.

## Files

- `task.py`: starter exercise.
- `solution.py`: completed answer.

## Learning Goal

- Build multi-branch condition trees.
- Understand when to nest logic and when to use `elif`.
- Keep branching code readable as it grows.
