# Higher or Lower Project

This project is the Day 14 higher-or-lower game. The player compares two entries and tries to guess which one has the higher value.

It is a good portfolio-style project because it feels like a complete game loop even though the underlying Python concepts are still beginner friendly.

## Files

- `solution.py`: reference solution.
- `art.py`: ASCII art for the game.
- `game_data.py`: data set used by the game.

## What It Demonstrates

- Working with a list of structured data.
- Randomly selecting entries for comparison.
- Building a repeatable game loop with scoring.
