# Logical Operators

This exercise demonstrates how to combine boolean expressions using `and`, `or`, and `not`.

That skill matters because real-world conditions are rarely as simple as one comparison. Programs often need to check several rules at once before taking action.

## Files

- `task.py`: starter exercise.
- `solution.py`: completed answer.

## Learning Goal

- Write compound conditions.
- Understand how boolean logic changes program flow.
- Practice reading conditions from left to right.
