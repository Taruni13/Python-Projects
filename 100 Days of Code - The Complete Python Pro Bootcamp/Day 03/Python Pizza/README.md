# Python Pizza

This exercise uses a pizza order scenario to practice conditional logic in a simple, familiar context.

The goal is to choose options based on the customer's selection, which makes the decision flow feel practical instead of abstract.

## Files

- `task.py`: exercise prompt.
- `solution.py`: reference solution.

## Learning Goal

- Translate a real-world ordering flow into `if`/`elif` logic.
- Practice reading a branching program from top to bottom.
- Connect beginner Python syntax with a familiar everyday problem.
