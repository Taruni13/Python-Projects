# Multiple Ifs

This exercise shows how to evaluate several conditions one after another, rather than stopping after the first branch.

That distinction matters when multiple rules can be true at the same time and each rule should trigger its own response.

## Files

- `task.py`: exercise prompt.
- `solution.py`: reference solution.

## Learning Goal

- Distinguish between separate `if` statements and chained branches.
- Understand how multiple conditions can run in one program pass.
- Practice writing readable rule-based logic.
