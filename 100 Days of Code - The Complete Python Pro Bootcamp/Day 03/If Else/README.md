# If Else

This exercise introduces the most basic form of decision-making in Python: choosing between two paths with `if` and `else`.

It is a core lesson because almost every interactive program depends on this pattern somewhere in the flow.

## Files

- `task.py`: exercise prompt.
- `solution.py`: reference solution.

## Learning Goal

- Understand conditional execution.
- Use indentation to define the scope of a branch.
- Build a simple two-path decision.
