# 100 Days of Code - Python Learning Projects

This repository is a learning portfolio built while working through the "100 Days of Code: The Complete Python Pro Bootcamp" Python course.

It contains beginner exercises, guided solutions, and small projects that show the progression from simple syntax to reusable code, conditional logic, loops, functions, dictionaries, debugging, and console games.

## What This Repository Shows

- A clear day-by-day learning path through the Python fundamentals.
- Starter exercises alongside completed solutions.
- Small interactive projects that demonstrate practical use of the concepts.
- A history of how the code evolved as the course introduced new topics.

## How To Use It

Most folders contain standalone Python scripts. Open the folder you want to inspect and run the relevant entry point:

```bash
python main.py
```

or

```bash
python solution.py
```

Some folders contain both a starter task and a completed solution. In those cases, `task.py` is the exercise prompt and `solution.py` is the finished reference answer.

## For Recruiters

This repository is intentionally structured to make progression easy to review:

- Early folders show syntax and basic control flow.
- Middle folders introduce functions, scope, data structures, and debugging.
- Project folders demonstrate how the same concepts combine into runnable programs.
- Folder-level README files explain the purpose of each lesson and the role of each file.
