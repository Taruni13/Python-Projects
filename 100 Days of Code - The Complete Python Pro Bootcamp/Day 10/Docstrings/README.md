# Docstrings

This lesson shows how to document functions with docstrings so other people can quickly understand what a function does.

Good documentation is part of writing professional code, even in small projects.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- Write simple docstrings.
- Explain the purpose of a function in plain language.
- Make code easier to understand for future readers.
