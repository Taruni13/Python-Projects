# Calculator Project

This is the Day 10 interactive calculator project. It combines functions, user input, repeated calculations, and a simple text-based interface.

The project is a good example of moving from isolated function exercises into a program that behaves like a small tool.

## Files

- `main.py`: runnable calculator app.
- `solution.py`: reference solution.
- `art.py`: calculator artwork.

## What It Demonstrates

- Using functions to handle repeated arithmetic.
- Accepting input from the user and turning it into calculations.
- Organizing a larger script into smaller responsibilities.
