# Functions with Outputs

This lesson focuses on return values. Instead of only performing an action, functions now produce data that the rest of the program can use.

That concept is crucial because it is what makes functions feel like tools instead of just instruction blocks.

## Files

- `solution.py`: completed solution.

## Learning Goal

- Use `return` to send a result back to the caller.
- Separate computation from printing.
- Build reusable functions that can feed into larger programs.
