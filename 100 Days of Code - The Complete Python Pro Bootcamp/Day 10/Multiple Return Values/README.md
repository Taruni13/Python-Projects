# Multiple Return Values

This lesson explains how a function can return more than one value when the result naturally contains multiple pieces of information.

That pattern appears often in practical code, especially when one calculation produces both a primary result and supporting details.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- Understand tuple-style return values.
- Read multiple outputs from a single function call.
- Use return values to keep logic compact and useful.
