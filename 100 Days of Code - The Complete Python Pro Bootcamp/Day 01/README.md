# Day 1

Day 1 introduces the absolute basics of Python. The exercises focus on printing text to the screen, receiving input, working with strings, storing values in variables, and choosing readable variable names.

This day matters because it teaches the first habit of writing code that is clear and easy to follow. The examples are simple on purpose so the syntax itself is easy to recognize.

## Contents

- [task/](task/): the Day 1 exercise folder.

## What To Look For

- How `print()` is used to display output.
- How string literals are written and combined.
- How variables store and reuse values.
- Why naming things clearly matters even in very small scripts.
