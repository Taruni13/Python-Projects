# Day 1 Task

This folder contains the lesson exercise and the completed answer for Day 1.

The files are intentionally small because the goal is to practice the very first Python building blocks before moving on to more complex logic.

## Files

- `task.py`: starter exercise that matches the lesson instructions.
- `solution.py`: completed reference solution for comparison.

## Learning Goal

The main goal is to get comfortable reading and writing the simplest possible Python program before the course introduces input, branching, and data types.
