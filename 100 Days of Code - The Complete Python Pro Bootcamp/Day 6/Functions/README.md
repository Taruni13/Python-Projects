# Functions

This exercise introduces Python functions as reusable blocks of code that can be called when needed.

It is one of the most important beginner topics because functions are what turn a script into something easier to organize, test, and extend.

## Files

- `solution.py`: reference implementation.

## Learning Goal

- Define a function with `def`.
- Call a function at the right time.
- Recognize how function-based code reads more clearly than repeated inline statements.
