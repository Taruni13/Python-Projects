# Lists

This exercise introduces Python lists as an ordered container for related values.

Lists are one of the most important beginner data structures because they make it possible to model groups of items and process them together.

## Files

- `task.py`: exercise prompt.
- `solution.py`: reference solution.

## Learning Goal

- Create and inspect lists.
- Read values by index.
- Understand how a single variable can hold many related items.
