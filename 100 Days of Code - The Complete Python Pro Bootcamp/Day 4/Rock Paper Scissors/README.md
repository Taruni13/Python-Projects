# Rock Paper Scissors

This is the full beginner game project for Day 4. It combines lists, randomness, and conditionals into a familiar game loop.

The project is useful because it shows how separate concepts can be stitched together into something interactive and recognizable.

## Files

- `task.py`: project prompt.
- `solution.py`: reference implementation.

## What It Demonstrates

- Choosing between multiple outcomes.
- Using randomness to simulate an opponent.
- Reading code that has both game state and game rules.
