# Banker Roulette

This exercise chooses a random person from a list, which is a simple way to practice list access and random selection.

The problem looks small, but it introduces a pattern used in many beginner projects: store options in a list and let Python choose one at random.

## Files

- `task.py`: exercise prompt.
- `solution.py`: reference solution.

## Learning Goal

- Understand how lists store multiple values.
- Use randomness to select an item.
- Practice building a tiny interactive utility from core Python pieces.
