# Random Module

This exercise shows how to use Python's `random` module for selection and number generation.

Randomness is a key ingredient in games, simulations, and many beginner projects because it makes programs less predictable and more interactive.

## Files

- `task.py`: starter exercise.
- `solution.py`: completed answer.

## Learning Goal

- Import and use `random`.
- Generate or select values unpredictably.
- See how randomness connects to game logic.
