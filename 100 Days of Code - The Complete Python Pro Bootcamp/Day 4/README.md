# Day 4

Day 4 focuses on collections and randomness. The exercises introduce lists, list indexing, the `random` module, and a full beginner game project.

This day matters because lists and randomness are the building blocks for most small games and many real automation tasks.

## Contents

- [Banker Roulette](Banker%20Roulette/): pick a random person from a group.
- [IndexError](IndexError/): learn what happens when list access goes wrong.
- [Lists](Lists/): create and use list data.
- [Random Module](Random%20Module/): work with random selection and numbers.
- [Rock Paper Scissors](Rock%20Paper%20Scissors/): a full beginner game project.

## What To Look For

- How to store related values in a single list.
- How to safely access list items by index.
- How randomness changes program behavior.
- How a simple game loop can be built from those concepts.
