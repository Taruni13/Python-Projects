# For Loops with Range

This lesson shows how `range()` can be used to control repeated work inside a loop.

It is a common beginner pattern for counting, iterating a fixed number of times, and building simple repeated behaviors.

## Files

- `task.py`: exercise prompt.
- `solution.py`: completed answer.

## Learning Goal

- Use `range()` to generate loop counts.
- Understand how a fixed-length loop behaves.
- Practice repetition with predictable boundaries.
