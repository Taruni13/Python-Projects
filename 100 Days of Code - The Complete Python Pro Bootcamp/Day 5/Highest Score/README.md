# Highest Score

This exercise uses a loop to find the largest value in a list, which is a classic example of reducing a sequence down to one result.

It is a useful pattern because many real tasks involve scanning through values and keeping track of the best, largest, or most recent one.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- Compare values while looping.
- Keep track of a running best result.
- Practice thinking in terms of list processing.
