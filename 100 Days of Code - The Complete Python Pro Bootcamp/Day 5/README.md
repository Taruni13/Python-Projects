# Day 5

Day 5 introduces repetition with loops. The lessons cover iterating over lists, using `range()`, finding the highest score in a sequence, and building a password generator.

This day matters because loops are one of the main tools that let Python work with collections and repeated actions efficiently.

## Contents

- [For Loops](For%20Loops/): iterate over items one by one.
- [For Loops with Range](For%20Loops%20with%20Range/): repeat actions a fixed number of times.
- [Highest Score](Highest%20Score/): find the largest value in a list.
- [Password Generator Project](Password%20Generator%20Project/): generate passwords from user choices.

## What To Look For

- How loops replace repetitive manual work.
- How `range()` controls repetition.
- How to compare values while iterating.
- How loops can be used to build practical utilities.
