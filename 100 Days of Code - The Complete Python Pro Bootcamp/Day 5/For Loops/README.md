# For Loops

This exercise introduces the basic Python `for` loop for stepping through a sequence one item at a time.

Once this pattern is understood, it becomes much easier to work with lists, strings, and any task that needs repeated processing.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- Understand loop syntax.
- Process each element in a sequence.
- Replace repeated manual code with a clean loop.
