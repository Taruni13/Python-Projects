# Use Print

This exercise demonstrates one of the simplest debugging techniques: adding print statements to inspect program state.

Even though it is basic, this method is still useful when you need a quick look at how values change during execution.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference answer.

## Learning Goal

- Inspect values without a debugger.
- Place print statements strategically.
- Use output to narrow down a problem.
