# Day 13

Day 13 is a debugging-focused day. Instead of introducing new Python syntax, it teaches how to think about broken code, trace execution, and diagnose common mistakes.

That skill is important because debugging is part of every real Python workflow, even when the code itself is simple.

## Contents

- [Describe the Problem](Describe%20the%20Problem/): read the bug carefully before changing code.
- [Fix the Errors](Fix%20the%20Errors/): correct syntax and logic mistakes.
- [Play Computer](Play%20Computer/): trace code manually.
- [Reproduce the Bug](Reproduce%20the%20Bug/): make the issue happen consistently.
- [Use Print](Use%20Print/): use print statements to inspect behavior.
- [Use a Debugger](Use%20a%20Debugger/): step through code with debugging tools.

## What To Look For

- A systematic way to approach bugs.
- Different debugging techniques for different situations.
- How careful reading often matters more than guessing.
