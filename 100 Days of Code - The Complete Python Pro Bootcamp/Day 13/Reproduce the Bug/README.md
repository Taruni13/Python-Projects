# Reproduce the Bug

This lesson focuses on making a bug happen consistently so it can be studied and fixed.

That approach is especially useful when a problem is intermittent or difficult to describe from memory.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference answer.

## Learning Goal

- Create a reliable failing case.
- Observe the conditions that trigger the bug.
- Fix problems from a position of evidence, not guesswork.
