# Use a Debugger

This lesson shows how to use a debugger to step through code and inspect state without adding temporary print statements.

It includes a small helper module so the exercise feels closer to real-world code that spans more than one file.

## Files

- `maths.py`: helper functions used by the exercise.
- `task.py`: starter exercise.
- `solution.py`: reference answer.

## Learning Goal

- Step through code line by line.
- Inspect values while the program is paused.
- Debug code in a more structured and repeatable way.
