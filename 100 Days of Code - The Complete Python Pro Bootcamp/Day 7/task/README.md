# Hangman Project

This folder contains the Day 7 Hangman project files.

The game is structured as a small multi-file program so the data, artwork, and main gameplay logic stay separate and easier to follow.

## Files

- `main.py`: the unfinished or in-progress game entry point used during the lesson.
- `solution.py`: the completed reference implementation.
- `hangman_art.py`: ASCII art and hangman stages used by the game.
- `hangman_words.py`: the word list that supplies random puzzle words.

## Learning Goal

- Understand how a game can be broken into multiple files.
- Practice using external data and artwork modules.
- Connect loops, conditionals, and lists into a working game flow.
