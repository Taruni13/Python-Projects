# Blind Auction Project

This project collects hidden bids from multiple users, stores the bids in a dictionary, and determines the winning offer.

It is a strong portfolio project because it combines dictionaries, control flow, input handling, and a small but complete user experience.

## Files

- `main.py`: runnable project.
- `solution.py`: reference solution.
- `art.py`: banner art for the project.

## What It Demonstrates

- Using a dictionary to map names to bids.
- Handling repeated user input in a multi-user flow.
- Turning a lesson topic into a polished command-line project.
