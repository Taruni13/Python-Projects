# Dictionaries

This lesson introduces dictionaries as Python's key-value data structure.

Dictionaries are important because they let code represent named pieces of information in a way that is much more expressive than a plain list.

## Files

- `task.py`: starter exercise.
- `solution.py`: reference solution.

## Learning Goal

- Create and access dictionary entries.
- Update values by key.
- Understand why key-based lookup is useful.
