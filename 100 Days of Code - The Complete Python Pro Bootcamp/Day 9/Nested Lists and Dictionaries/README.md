# Nested Lists and Dictionaries

This exercise works with structured data that contains lists inside dictionaries or dictionaries inside lists.

The lesson matters because many real datasets are nested, and learning how to navigate them is a necessary step toward more advanced Python work.

## Files

- `task.py`: exercise prompt.
- `solution.py`: completed answer.

## Learning Goal

- Read nested collection structures.
- Understand how related data can be grouped more realistically.
- Practice indexing and key lookup together.
