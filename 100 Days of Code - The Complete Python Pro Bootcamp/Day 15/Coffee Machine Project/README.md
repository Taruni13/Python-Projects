# Coffee Machine Project

This project simulates a small coffee machine in the terminal. The user chooses a drink, the program checks resources, and the machine updates its internal state as drinks are made.

It is one of the most practical beginner projects in the course because it introduces the idea of modeling a system with data and functions.

## Files

- `main.py`: runnable coffee machine program.
- `solution.py`: reference solution.

## What It Demonstrates

- Managing inventory-like state.
- Combining functions into a larger workflow.
- Making a program respond to user choices in a realistic way.
