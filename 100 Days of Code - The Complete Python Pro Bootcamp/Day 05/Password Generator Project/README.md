# Password Generator Project

This project combines loops, randomness, lists, and user choices to generate passwords with different character mixes.

It is one of the first lessons that feels like a real utility because the output is something a user could immediately use.

## Files

- `task.py`: project prompt.
- `solution.py`: working solution.

## What It Demonstrates

- Building output from user-selected rules.
- Repeating choices with loops.
- Using Python to automate a small but useful task.
